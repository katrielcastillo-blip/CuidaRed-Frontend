# Iconos de CuidaRed

Material Symbols Outlined de Google, autoalojado. Subconjunto de 150 iconos, peso 400 y FILL 0/1. Licencia Apache 2.0 adjunta.

Origen: [Guía oficial](https://developers.google.com/fonts/docs/material_symbols). Se regenera con `node scripts/preparar-iconos.mjs`; no se consulta Google Fonts al usar la PWA.

Montserrat y Open Sans se importan desde sus paquetes Fontsource, con subconjuntos latinos autoalojados. Sus licencias SIL Open Font License 1.1 se conservan en `MONTSERRAT-LICENSE.txt` y `OPEN-SANS-LICENSE.txt`.
